# 2048 Game - Java

A console-based 2048 game built in Java using 2D arrays and game logic.

## Features

- 4x4 game board
- Random tile generation
- Tile movement in four directions
- Tile merging
- Score calculation
- Invalid move detection
- Game over detection
- 2048 win condition
- Restart option
- Console-based controls

## Controls

| Key | Action |
|-----|--------|
| W | Move Up |
| A | Move Left |
| S | Move Down |
| D | Move Right |
| Q | Quit Game |

## Technologies Used

- Java
- 2D Arrays
- Object-Oriented Programming
- Random Number Generation
- Console Input
